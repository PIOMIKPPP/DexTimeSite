# 🟩 Bedrock Craft — сайт Minecraft-сервера для GitHub Pages

Готовый сайт в тёмно-сером стиле (как [bedrocklauncher.github.io](https://bedrocklauncher.github.io/)) с рабочим форумом,
регистрацией/авторизацией, админ-панелью создателя и кнопкой скачивания сборки модов.

Сайт — **статический** (HTML + CSS + JS, без бэкенда), поэтому бесплатно хостится на GitHub Pages.
Форум работает в двух режимах:

| Режим | Что нужно | Как работает |
|---|---|---|
| **Локальный** (по умолчанию) | ничего | Данные хранятся в браузере (localStorage). Подходит «пощупать» сайт, но **каждый посетитель видит только свои темы** |
| **Онлайн** (рекомендуется) | бесплатный аккаунт Supabase | Настоящая общая база: форум, регистрация и админка работают для всех игроков |

## 📁 Что лежит в архиве

```
site/
├── index.html            — страница сайта (вся разметка)
├── style.css             — тёмно-серый OreUI/Minecraft дизайн
├── app.js                — вся логика: форум, аккаунты, админка
├── config.js             ← НАСТРОЙКИ САЙТА (название, IP, ключи Supabase)
├── supabase_setup.sql    — скрипт базы данных для онлайн-режима
├── ИНСТРУКЦИЯ.md         — этот файл
├── assets/
│   └── hero-bg.jpg       — фон шапки (можно заменить своим)
└── mods/
    ├── server-mods.zip   ← СЮДА кладём сборку модов
    └── СЮДА_КИДАТЬ_АРХИВ.txt — подсказка
```

Архив для загрузки: **`github-server-site.zip`** (всё это уже упаковано).

## 🚀 Быстрый старт (3 шага, ~10 минут)

### Шаг 1. Загрузите файлы на GitHub

1. Зайдите на [github.com](https://github.com) → **New repository** (зелёная кнопка справа сверху).
2. Назовите репозиторий, например: `my-mc-server`.
   - Поставьте **Public** (иначе GitHub Pages на бесплатном тарифе не включится).
   - Можно поставить галочку **Add a README file**.
   - Нажмите **Create repository**.
3. В открывшемся репозитории нажмите **Add file → Upload files**.
4. Перетащите в окно **содержимое папки `site`** — то есть файлы `index.html`, `style.css`, `app.js`,
   `config.js`, папки `assets` и `mods`.
   > ⚠️ Важно: файл `index.html` должен лежать **в корне репозитория**, а не в папке.
   > Внутри репозитория **не** должно быть папки `site`, иначе сайт не откроется.
5. Внизу нажмите зелёную кнопку **Commit changes**.

### Шаг 2. Включите GitHub Pages

1. В репозитории откройте вкладку **Settings** (шестерёнка сверху).
2. Слева выберите **Pages**.
3. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (или `master`), папка `/ (root)`
4. Нажмите **Save**.
5. Подождите 1–2 минуты и обновите страницу — сверху появится зелёная плашка:
   **Your site is live at https://ВАШ-НИК.github.io/my-mc-server/**

Готово! Сайт работает. 🎉

> Если сайт открывается, но без стилей (чёрный текст на белом фоне) — значит вы загрузили
> файлы внутрь лишней папки. Проверьте, что `index.html` лежит в корне.

### Шаг 3. Закиньте сборку модов

Откройте папку `mods/` в репозитории и замените файл `server-mods.zip` своей сборкой
(имя файла лучше оставить `server-mods.zip`, чтобы не менять `config.js`).

**Как заменить через браузер:** зайдите в папку `mods` → справа сверху **Add file → Upload files** →
перетащите новый `server-mods.zip` → **Commit changes**. Старый файл с таким же именем перезапишется.

**Если сборка весит больше 25 МБ** (GitHub ограничивает размер файла ~100 МБ, а комфортно — до 25 МБ):

1. В репозитории справа нажмите **Releases → Create a new release** (или **Draft a new release**).
2. Тег: `v1.0`, название: `Сборка модов 1.21.4`.
3. В низ страницы перетащите ваш `server-mods.zip` в поле **Attach binaries**.
4. Нажмите **Publish release**.
5. Скопируйте ссылку на файл (нажмите правой кнопкой на названии файла → **Копировать ссылку**),
   она выглядит так:
   `https://github.com/ВАШ-НИК/my-mc-server/releases/download/v1.0/server-mods.zip`
6. Откройте `config.js` и вставьте эту ссылку:
   ```js
   MODS_DOWNLOAD_URL: "https://github.com/ВАШ-НИК/my-mc-server/releases/download/v1.0/server-mods.zip",
   ```
   Сохраните (кнопка **Commit changes**).

## 🌐 Подключение онлайн-базы (чтобы форум был общим) — бесплатно, ~5 минут

Без этого шага сайт уже работает, но форум у каждого игрока «свой» (данные в браузере).
Supabase — это бесплатная база данных + готовая регистрация по email/паролю.

1. Зайдите на [supabase.com](https://supabase.com) → **Start your project** (войдите через GitHub).
2. **New project**: любое имя, регион `Europe (Frankfurt)` или любой другой, пароль БД — придумайте
   и **сохраните**. Ждите создания (~2 минуты).
3. Слева откройте **SQL Editor** → **New query**.
4. Откройте файл `supabase_setup.sql` из архива, скопируйте **весь** текст, вставьте в окно
   и нажмите **Run** (или Ctrl+Enter). Должно появиться `Success. No rows returned`.
5. Слева **Project Settings** (шестерёнка) → **API**. Оттуда скопируйте:
   - **Project URL** — вида `https://xxxx.supabase.co`
   - **Project API keys → `anon` `public`** — длинная строка
6. Откройте в репозитории файл `config.js` → кнопка карандаша ✏️ (Edit) и вставьте:
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "ваш-длинный-anon-ключ",
   OWNER_EMAIL: "ваша@почта.ru",   // этот email автоматически получит роль Создателя
   ```
   Нажмите **Commit changes**.
7. Откройте **Authentication → Providers → Email** и, если хотите регистрироваться без подтверждения
   письма, отключите **Confirm email**. (Обязательно ли это — нет, но новичкам так проще.)

Всё. Теперь регистрация, вход, темы, ответы и админка работают онлайн для всех игроков.

## 👑 Админка создателя

**Как получить права Создателя:**

- Зарегистрируйтесь на сайте **первым** — первому пользователю роль `owner` выдаётся автоматически, **или**
- Зарегистрируйтесь с email, указанным в `ownerEmail` (в `config.js` и в `supabase_setup.sql`
  в функции `handle_new_user`), — он тоже получит роль `owner`.
- В локальном (без Supabase) режиме в форме входа есть тестовый аккаунт: **`admin` / `admin123`**.

**Что умеет админка** (вкладка **«Админка»** в шапке видна только владельцу/модераторам):

- **Общее** — название сервера, IP, версия, загрузчик, ссылки Discord/Telegram/GitHub/донат,
  баннер-объявление (текст + вкл/выкл). Меняется прямо на сайте, без правки файлов.
- **Сборка модов** — описание, версия, размер, дата обновления, список модов, ссылка на архив.
- **Пользователи** — поиск, выдача ролей (Игрок / Модератор / Админ / Создатель), бан/разбан,
  удаление всех сообщений нарушителя.
- **Форум** — создание и удаление разделов, закрытые разделы только для администрации,
  удаление и модерация тем.
- **Правила / FAQ** — редактирование текста правил и ответов на частые вопросы.
- **Экспорт/сброс данных** — в локальном режиме.

> В онлайн-режиме все изменения из админки сохраняются в базу Supabase и видны всем игрокам.

## ⚙️ Настройка сайта под себя

Все базовые настройки — в файле **`config.js`** (открыть в GitHub → карандаш ✏️ → править → **Commit changes**):

| Поле | Что меняет |
|---|---|
| `SUPABASE_URL` / `SUPABASE_ANON_KEY` | Подключение онлайн-базы (пустые = локальный режим) |
| `OWNER_EMAIL` | Email, который получит роль Создателя |
| `SERVER_NAME` | Название сервера в шапке |
| `SERVER_TAGLINE` | Подзаголовок на главной |
| `SERVER_NOTICE` | Текст под кнопками на главной |
| `SERVER_IP` | IP для кнопки «Копировать IP» |
| `MINECRAFT_VERSION` / `MOD_LOADER` | Например `1.21.4` / `Fabric` |
| `MODS_DOWNLOAD_URL` | Путь к архиву сборки (`mods/server-mods.zip`) или внешняя ссылка |
| `MODS_VERSION` / `MODS_SIZE` / `MODS_UPDATED` / `MODS_DESCRIPTION` | Информация о сборке модов |
| `DISCORD_URL` / `TELEGRAM_URL` / `GITHUB_URL` / `DONATE_URL` | Ссылки в подвале и шапке (пусто = скрыть) |
| `DEMO_OWNER_LOGIN` / `DEMO_OWNER_PASSWORD` | Тестовый вход `admin` / `admin123` (только локальный режим) |

Фон шапки: замените `assets/hero-bg.jpg` своим скриншотом (рекомендуемый размер 1920×1080 или 1376×768).

## ❓ Частые вопросы

**Сайт открывается, но пустой/белый**
→ Проверьте, что `index.html`, `style.css`, `app.js`, `config.js` загружены в корень репозитория.

**Не работает регистрация**
→ Значит не подключён Supabase: в `config.js` пустые `url`/`anonKey`, и сайт работает в локальном режиме.
Либо в Supabase включено подтверждение email — проверьте почту или отключите **Confirm email**.

**Кнопка «Моды для сервера» качает пустой архив**
→ Это заготовка. Замените `mods/server-mods.zip` на свою сборку (см. Шаг 3).

**Изменения на сайте не появляются**
→ GitHub Pages обновляется 1–2 минуты. Нажмите Ctrl+F5 (жёсткая перезагрузка).

**Хочу свой домен**
→ GitHub Pages → раздел **Custom domain** → впишите домен и добавьте CNAME-запись у регистратора.
