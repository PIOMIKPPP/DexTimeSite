Замените файл server-mods.zip в этой папке (mods/server-mods.zip) на ваш ZIP-архив с модами.
Кнопка «Моды для сервера» / «Скачать сборку (.zip)» на сайте автоматически скачивает файл mods/server-mods.zip.

ВАЖНО про лимит GitHub:
- Через браузер на GitHub можно загружать файлы до 25 МБ (через Git — до 100 МБ).
- Если ваша сборка server-mods.zip весит больше 25–100 МБ, загрузите её в раздел Releases
  вашего репозитория GitHub (там лимит до 2 ГБ на файл бесплатно!), скопируйте ссылку на .zip
  и вставьте её в Админке сайта (вкладка «Сборка модов») или в файле config.js (MODS_DOWNLOAD_URL).
